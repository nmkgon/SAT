# Vertex Word Problems

Password: **Sat800**. Open **wordproblems.html** from the Vertex index.

- 160 source problem families across Algebra, Advanced Math, Data, and Geometry.
- 19 topic sets with Study and 10-question checks; topic checks use study mode, with solutions available.
- A 44-question mixed timed rehearsal with two 35-minute modules. The score is a practice estimate.
- Worked solutions, replayable models, and offline number variants in movable windows.
- Gemini / LM Studio generation, shared AI keys and monthly budget tracking.
- Independent saved progress, reports, missed-question review packs and study guides.

Select **Animated model** below a revealed solution. Replay the model, drag the progress slider, or select a solution step to highlight that step. Close the window to return to the same problem. **New number variant · Offline** saves a new set without an API call. Offline variants follow the source family; use AI generation for a selected difficulty level.

Graphs required by a question display with the question. Explanatory animations stay with solutions. Exported printable guides include static question diagrams; interactive animation stays in the main Word Problems page.

Keep the assets and config folders intact when uploading to GitHub. The older WordLab interface and its saved progress remain separate.
