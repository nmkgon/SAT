# Native conversion notes

No question or solution depends on a PDF page or scan. The ten Panda tests map to Vertex Tests 4–13. Test 4 is retained from the preceding native conversion.

Each full test uses the original 20-question / 25-minute section and 38-question / 55-minute section. Scores are raw accuracy, not official scaled SAT scores. Open index.html after extracting the complete package. Existing passwords and shared AI settings follow the original app.

The supplied package contains Test 1, Test 2, and the Word Problems collection, but no separate test3.html; these have been retained.

Question wording is lightly edited for standalone use. Charts are vector reconstructions from the source; unlabeled scatterpoint positions are approximate. All answer-relevant relationships and values are retained. Native source banks are in native-data/.
