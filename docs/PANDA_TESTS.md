# Panda tests

Panda Tests 1–10 map to Vertex Tests 4–13. Each contains 58 questions in the original 20-question and 38-question sections. Section 3 allows 25 minutes without the calculator; Section 4 allows 55 minutes. Study mode allows the calculator and solution review.

Questions, equations, choices, solutions, and figures are embedded within each test HTML file. Open index.html for the full launcher.
