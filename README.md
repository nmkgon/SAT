## GitHub Pages
Upload the complete contents, preserving these folders. Keep index.html and test1.html at the same website path as before to retain browser settings and progress. Retain .nojekyll.

## Local use
With Python installed, open **tools/start-local.bat**, or run `python tools/serve-local.py` from the package root. The server opens http://localhost:8080.

## Adding a test
Put test2.html beside test1.html, then update config/tests.js to make its entry ready. Test 2 is currently a placeholder.
